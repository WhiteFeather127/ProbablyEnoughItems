# Probably Enough Items v0.2.1

《深空当铺》（Probably Stolen）的物品与合成查看模组。适配游戏 **0.46D**。

## v0.2.0 以来的更新

### 夜巡拾荒系统

- **拾荒产出池**：捕鼠夹、螺丝刀（×10 权重）、金属螺母、剪线钳（×10 权重）、电线、焊接器、废金属 + 稀有发现（挎包 / 儿童背包）——`ScavHelper.GetRandomScavengedItem` 的硬编码清单，注入为 `scav_afterhour` 池
- **拾荒道具**：金属探测器（拿来升级基地探测器，每级提高双倍掉落几率）、手电筒（夜巡降低受伤几率）
- 补映射漏掉的倾倒场医疗废料池 `dumpingGroundMedical`

### 掉落池：映射与显示统一

- **同一地点的全部池子合并成一页**（垃圾倾倒场：垃圾堆 + 残骸 + 医疗废料 + 拾荒 + 背包发现），不再按表拆成几页
- **反查可达性由构造保证**：`LootSource.EnsureBuilt` 末尾把「池 × 物品」重放登记反查索引——站点页上出现的每个物品，构造上必然能从它的来源页反查回站点
- 组表直塞的物品 id、手工池、占位展开统一兜底，不再有独立的登记通路

### 真实物品 id 规则（AGENTS.md 数据层规则落地）

- 真实 id 解析器下沉为数据层唯一入口 `LootSource.BaseItemId`：`random_*` 占位展开成同族默认模块、满装盒旧命名对上游戏自己的 `*_container`、运行时改名瓶借本体、状态后缀递归剥离
- 随机模块占位（`random_performance_module` 等）在池子里**直接显示同族默认模块**，不再随机生成实例
- 具体模块（`system_module_quality` 等）的来源页能查到倾倒场与工程箱；迷你酒精瓶借 `mini_bottle` 本体反查化学品拆包

### 修复

- 文字格清理：POI 节点 id（junk_pile 等，非物品）过滤；`full_*` 满装盒格子全部有图标可点
- 「机器」大类补进用途窗口（此前只在来源窗口，用途窗口里的机器只剩一条琐碎使用记录）

## 安装

解压到游戏的 `Mods` 目录，或运行仓库里的 `install.ps1`。
