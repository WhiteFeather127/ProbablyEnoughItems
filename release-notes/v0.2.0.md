# Probably Enough Items v0.2.0

《深空当铺》（Probably Stolen）的物品与合成查看模组。适配游戏 **0.46D**。

## 安装

解压到游戏的 `Mods` 目录（保持 `ProbablyEnoughItems` 文件夹结构），或运行仓库里的 `install.ps1`。需要游戏本体支持 BepInEx 式模组加载（仓库 README 有说明）。

## v0.1.1 以来的主要更新（47 个提交）

### 新功能

- **机器页**：机器的详情窗口还原机器界面——电池 / 模块 / 功能槽 / 7×5 容器网格（面板序列抄自各机器类 IL，标签跟随游戏语言），下半部分是它的产出配方（工具 = 必需模块、材料 = 原料、产物）。来源窗口和用途窗口都有。
- **拾荒系统**：夜巡拾荒的固定产出池（捕鼠夹 / 螺丝刀 / 金属螺母 / 剪线钳 / 电线 / 焊接器 / 废金属 + 稀有背包）和道具（金属探测器升级双倍掉率、手电减伤）全部可查。
- **化学品拆包**：普通 / 管制化学品补给的激活产物（迷你酒精瓶 ×2、脂多糖试剂、酸瓶、碱瓶；芬达前体 ×2、还原剂瓶）、果箱与真空包装谷果拆包、消耗品全集（药片 / 注射器 / 烟 / 酒）进使用表。
- **液体管理器**：配方里的液体需求（游戏里是容器内容物而非物品）统一展示成容器 bottled_water，可点可查。

### 修复

- **箱子反查**：箱内物品的来源页能查到箱子（`*_container` / 满装盒对上游戏目录的真身），箱子页与物品页从两个方向看是同一页。
- **地点掉落页**：同一地点的全部池子合并成一页（垃圾倾倒场：垃圾堆 + 残骸 + 拾荒 + 背包发现），不再按表拆成几页；POI 节点 id 这类非物品条目过滤掉。
- **文字格清理**：满装盒（`full_*`）映射到目录真身；运行时改名的迷你酒精瓶借 mini_bottle 图标；多选拖拽删除的红底挂到幽灵节点下，与物品同步移动。

### 界面

- 大类标题字号放大；使用页去掉冗余标签（方向 / 方式 / 使用的物品），「产物」保留作分界线；窗口物品名标题每轮渲染强制居中。

## 数据与对账

- `Data/*.csv`（客人 / 箱子 / 掉落池 / 用途）与游戏 IL 的对账脚本在 `tools/audit/`（30+ 个探针），改表后跑一遍即可核对。
- 掉落池映射了游戏 0.46D 的 14 张运行时表 + 2 个组 + 夜巡拾荒手工池。
