[h1]Probably Enough Items[/h1]
Мод-каталог: откуда берётся предмет и для чего он нужен. Читает каталоги предметов, списки клиентов и подсказки игры, без нового формата данных.

Собирает все 27 каталогов предметов игры и записи других модов в одну панель. Неиспользуемые и отладочные записи по умолчанию скрыты.

[hr][/hr]
[h2]Открытие[/h2]
[list]
[*][b]Открыть каталог[/b]: кнопка «Каталог» у правого края окна инвентаря
[*][b]Перелистывание[/b]: кнопки внизу; текущая страница — x / y
[/list]

[h2]Поиск[/h2]
[list]
[*][b]По названию[/b]: введите название в поле поиска сверху
[*][b]По id[/b]: введите id, например [b]water[/b]
[*][b]По типу[/b]: например [b]роскошь[/b], [b]предметы быта[/b] или [b]документы[/b]
[*][b]По тегу[/b]: например [b]ADV_GUN_TAG[/b]
[/list]

[h2]Подсказки[/h2]
[list]
[*][b]ID предмета[/b]: при наведении в подсказку добавляется строка ID
[*][b]Состав и примеси[/b]: для контейнеров также диапазоны
[/list]

[h2]Подробности предмета[/h2]
[list]
[*]Типы предмета перечислены под заголовком, как в подсказке
[*][b]Источники[/b]: ЛКМ
[*][b]Применение[/b]: ПКМ
[*]С обеих сторон — категории, переключаемые кнопками [b]< Категория >[/b]
[*][b]Окно[/b]: окно подробностей можно перетаскивать за любое место; Esc закрывает его
[/list]

[/tr]
[tr]
[td]Применение[/td]
[td]Обе[/td]

[/tr]
[tr]
[td]Ремонт оружия[/td]

[/tr]
[tr]

[td]Применение[/td]

[/tr]
[tr]

[td]Обе[/td]
[td]Контейнеры, локации и броски, которые его выдают; пулы одной локации объединены[/td]
[/tr]
[/table]

[h2]Варианты[/h2]
[list]
[*]Перечисляемые варианты занимают отдельные ячейки: сигареты 5, инъекторы иммунитета 5, продовольственные талоны 30, модули по форме и эффекту, ягоды 6, размеры урожая
[*]ДНК-диски: пустой диск — отдельная ячейка; записанные — по одному на признак растения (по 1 использованию), с переходом к странице извлечения
[*]Жидкости: каждая чистая жидкость всегда показана полной бутылкой
[*]Рецепты с сортами урожая дублируются по сортам, в ячейке материала — значок сорта
[*]Непрерывно меняющиеся значения остаются в одной ячейке и фиксируются одним образцом
[/list]

[h2]Страницы клиентов[/h2]
[list]
[*]Контейнеры показывают воду, которую наливает именно этот клиент
[*]На страницах «Требуется» — что клиент покупает: теги типов и предметы; вода показана уровнем качества, состав — в подсказке
[/list]

[h2]Взятие предметов[/h2]
[list]
[*][b]Чит-режим[/b]: включите его в правом верхнем углу, затем вытащите предмет из ячейки перетаскиванием — вы получите одну копию, образец останется в ячейке
[*]Пока он включён, брошенный на панель предмет удаляется — при перетаскивании под ним появляется красная подсветка
[*]Без него щелчок только открывает подробности, вытащить предмет нельзя
[/list]

[h2]API расширений[/h2]
[list]
[*][b]Варианты[/b]: другие моды вызывают API через рефлексию, без зависимостей
[*][b]Записи[/b]: можно добавлять целые записи каталога
[/list]
